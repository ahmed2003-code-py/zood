# Architecture Decision Records

An ADR is a short file that records one technical decision for ZAWED: the context, what we decided and what follows from it. To add one, take the next number, copy the template of an existing ADR (Status, Source, Context, Decision, Consequences) and add a row to the table below. Never edit the decision of an accepted ADR; supersede it with a new ADR that says which one it replaces, and update the status of the old one.
