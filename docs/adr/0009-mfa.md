# ADR 0009: MFA

**Status:** Accepted, 2026-11-12
**Source:** `docs/architecture/implementation-plan.md` §4, decision 9

## Context
Ops and Super Admin can change money-affecting data, so they are the highest-risk accounts (PRD §10.2). The roadmap delta (A3) adds station financial roles once stations have payouts and bank details, which arrive in B6.

## Decision
- TOTP is required for Ops and Super Admin from B1.
- TOTP is added for station financial roles in B6.

## Consequences
- Internal admin fraud is harder: a stolen password alone is not enough.
- B1 must include TOTP enrolment and verification, with recovery handled by Ops or Super Admin procedure.
- Station financial roles stay without MFA until B6, when payouts and bank-detail changes exist.
- MFA protects bank-detail change control and dual control on payouts, which also land in B6.
